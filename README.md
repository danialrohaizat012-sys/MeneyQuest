# Meney Quest V0.6 — Shop Floor Deluxe

A coded, playable browser prototype inspired by the approved Meney Quest mockup.

## What is coded
- Desktop game dashboard with top, left, right and bottom HUD
- Interactive customer characters
- Full dialogue bubbles that wrap text correctly
- Slower five-minute shift
- Much slower patience decay
- Sales, Repair, Trade-In and Cashier clickable stations
- Current order and upcoming customer panels
- Coins, reputation, combo, goals, HQ XP and statistics
- Pause and restart flow
- Local best-score save

## Visual note
The detailed shop interior uses the generated Meney concept artwork as the environment layer.
Characters, dialogue, HUD, patience, state changes and game logic are HTML/CSS/JavaScript.

## Run
Open `index.html` in Chrome.
Best experienced on a laptop/desktop due to the full dashboard layout.
